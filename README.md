Kraken spot paper bot — stub ticker.

## Features

- Venue kraken / XBTUSDT
- Strategy id ema
- Paper engine and stub candles
- Risk cap on notional / equity

## Prerequisites

- Go 1.22+
- Git

## Getting Started

```bash
git clone <repo-url>
cd kraken-spot-bot
make build
./bin/krakenspot -help
```

## CLI Usage

```bash
make test
go run ./cmd/krakenspot -help
```

## Project Structure

```
cmd/krakenspot/main.go
internal/engine/engine.go
internal/engine/engine_test.go
```

Kraken Go scripts use kraken-spot-bot.
